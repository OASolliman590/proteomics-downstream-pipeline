## Engineering notes

- **Source-first.** Each figure is written as a source table first (`sources/<figure_id>.tsv`). The three outputs are rendered from that table. A post-render check re-reads the table and compares it with each output (R16b, R16c, R16d oracles).
- **Stable colours (R16a).** The group colour map is built once per run from the declared group order and reused for every output.
- **PNG (R16c).** The width in inches is the preset in mm divided by 25.4. The pixel width is that value times 300, rounded to the nearest integer. Arial is used if available. If not, the substitute is recorded in the registry and the theme check reports it.
- **HTML (R16d).** The vendored file is hashed before embedding and the hash is compared with `PINNED.json`. The data are embedded as JSON; the static scan runs over the complete written file.
- **pzfx (R16b).** The writer is a standard-library XML writer. Its self-check parses the written XML and compares values with the source before the file is registered. Reading back with `pzfx::read_pzfx` is an independent oracle where that package is installed.
- **Catalogue (R16e).** Each figure has one V case that checks the three outputs against the same source table. The figures reuse the source-table families of their analyses and do not recompute the statistics.
- **Fixtures.** Synthetic only, generated by a fixture factory shared with the existing synthetic PERMANOVA, post-DE and pathway fixtures, so no study data enter the public repository.
- **Evidence.** Commands, versions, hashes and exit codes go into packet-local evidence. Prism-openability is recorded as a Maintainer manual check (NOT_RUN in automated tests).
