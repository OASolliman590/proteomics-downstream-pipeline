# Specification quality checklist

This checklist evaluates specification readiness, not implemented software.

- [x] User journeys, explicit downstream boundary and measurable acceptance outcomes are defined.
- [x] Constitution states experimental identity, method eligibility, inference semantics, provenance and reviewer responsibilities.
- [x] Twelve slices have bidirectional roadmap links and individual spec/plan/tasks artifacts.
- [x] 120 globally unique requirements/tasks/acceptance cases have a machine-readable traceability register.
- [x] CLI, file, data-model and structural/semantic configuration contracts are explicit.
- [x] Structural schema and three examples validated with an actual Draft 2020-12 validator.
- [x] Scientific primary sources were opened and method-specific API/applicability concerns recorded.
- [x] Independent methods review identified and corrected proDA all-missing-group, fixed/random blocking, no-bridge TMT, count positivity, family failure and prior-imputation distinctions.
- [x] Corrected packet index gives every packet an ID, goal, exact allow/forbid boundary, packet-ID dependencies, acceptance lines and risk.
- [x] Only R06/R07/R09 are marked parallel, with disjoint named files and no mutual dependencies.
- [x] Maintainer/Independent Reviewer/Packet Implementer ownership, receipts, audit/freeze/go gates, private-evidence isolation and Maintainer-only closure are explicit.
- [x] Historical source hash checks and local document-link/traceability validation are provided.
- [x] Future commands/features are labeled implementation targets rather than existing or validated functionality.
- [ ] Independent specification audit completed and maintainer freeze recorded — mandatory before any implementation packet.
- [ ] Full maintained pipeline implemented and independently tested — responsibility of frozen Packet Implementer packets and Maintainer verification/closure.
- [ ] Scientific calibration, clean-environment validation and local study regression executed — future implementation gates.
- [ ] Publication rights/license decided — outside this one-shot implementation mandate.
