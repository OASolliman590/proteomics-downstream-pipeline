# Scientific methods contract v1.1.0

Status: **frozen** under kit 1.2.0. This contract specifies a future maintained implementation; it does not correct the recovered scripts in place. Numeric constants below are prespecified product policies, not claims that those cutoffs establish biology. Sources and API qualification are in [research.md](../research.md); acceptance cases are in slices 002–013.

Every rule below specifies its trigger, required and forbidden behavior, public result type, family and diagnostic output. `none` means no multiplicity adjustment and no inferential P/q fields. A named family is resolved from the frozen `multiplicity_families` configuration, not constructed after seeing results. Technical identifiers in this contract are case-sensitive.

### Scale transitions

| Source state | `preprocessing.transform` | Output / eligibility |
|---|---|---|
| `linear_positive` | `log2` | Positive observed values become log2 once. Explicit encoded missing zeros become NA before transforming. Undeclared zero or negative observed values fail. |
| `linear_positive` | `none` | Descriptive QC only; abundance inference fails `E_LOG2_REQUIRED`. |
| `log2` | `none` | Preserve values, including zero and negative log2 values. |
| `log2` | `log2` | Hard failure `E_SCALE_SECOND_LOG`. |
| `ratio_log2` | `none` | Preserve ratio estimand and declared reference; eligible linear inference describes log2-ratio differences, not absolute abundance. |
| `ratio_log2` | `log2` | Hard failure `E_SCALE_SECOND_LOG`. |
| `standardized_unknown` | `none` | Descriptive QC only; inference fails `E_SCALE_UNKNOWN_INFERENCE`. |
| `standardized_unknown` | `log2` | Fail `E_SCALE_TRANSFORM_UNJUSTIFIED`. |

For technical `mean_linear`, average declared positive linear observations before the single log2 transition. For `mean_log2`, transform once first if needed and average log2 observations. Linear [4,16] therefore gives log2(10) versus 3, respectively. Neither mean increases biological n. An already log2 input cannot request `mean_linear` without an explicitly specified reverse-scale sensitivity; that reverse-scale route is not exposed in this version.

Normalization is prespecified: `preserve`; log2 LFQ `median` centering by each observation's observed median relative to the median of those medians; `reference` centering using the declared covered reference proteins; or `tmt_loading` within plex. Reference failure is `E_REFERENCE_COVERAGE`. TMT declares `upstream_preserved`, `bridge` or `no_bridge`: bridge mode requires its actual channels, while no-bridge mode requires identifiable replicated within-plex effects and plex terms. Missing bridge is `E_TMT_BRIDGE_REQUIRED`; confounding is a design error. Ratio compression is not claimed corrected. Quantile normalization is a named normalization sensitivity only, not a hidden default for dropout analysis.

SM04 TMT loading/bridge result is PreprocessingResult (no family; V023): compute each channel's observed log2 median and subtract its difference from the within-plex median of channel medians. For declared bridge mode, b_fp is the median of that feature's normalized bridge-channel values in plex p; b_f is the median of available b_fp across declared plexes. Adjust analytical values as y_fpc−b_fp+b_f. A feature lacking its required plex bridge measurement is ineligible for cross-plex bridge inference, with a recorded reason, not filled or switched to another method. Reference-channel observations remain in source/QC metadata but are marked reference-only in the frozen plan and never counted as biological units. No-bridge inference retains its explicit identifiable plex terms. Quantile normalization sensitivity uses pinned limma::normalizeBetweenArrays(method="quantile") on a declared complete-case sensitivity matrix; record lost rows, not hidden imputation.

`min_deterministic` replaces each missing cell with that feature's minimum observed retained log2 value across all groups; an all-missing feature has no replacement and is excluded. `left_shifted_gaussian` uses each observation's observed log2 mean and sample SD across retained features, draws N(mean − shift_sd×SD, (scale_sd×SD)^2), and records positive configured shift/scale, seed and draw ordering (feature ID, then observation ID). Undefined/zero SD yields `E_IMPUTATION_DISTRIBUTION`, not fabricated draws. `knn` uses pinned `impute::impute.knn` with explicitly recorded k/rowmax/colmax/maxp/rng.seed and reports the package's fallback behavior; all-missing rows/columns are rejected and every replacement stays sensitivity-only. `complete_case` fits only features observed across the design's required observations, records its reduced universe and performs no fill. Algorithms never inspect group labels when choosing donors or fill parameters.

A prior-imputed input needs the original-observed mask to pass primary observed-coverage rules. When that mask is unknown, QC reports numeric availability and unknown observed coverage; primary inference fails `E_ORIGINAL_MASK_REQUIRED`. A declared sensitivity may describe the already-imputed input but cannot acquire the primary observed-data label. Detection-only analysis requires a genuine mask: independent two-group Fisher exact tests form `DetectionResult` in their own secondary family. Paired/complex detection yields `E_DETECTION_DESIGN_UNSUPPORTED` and no detection P values.

| SM08 — Nonorthogonal, missing, weighted, paired or blocked design | Use exact contrast-as-coefficient reparameterization and refit with identical weights/block correlation, or an independently verified mathematically equivalent featurewise GLS covariance. | SM09 — Primary differential abundance | Default to limma on eligible declared log2 abundance. Fit with frozen trend/robust settings (defaults true/true, statmod required); export moderated variance/df and diagnostics. | Hit-count engine selection; new primary imputation; calling robust eBayes robust sample regression. | `ProteinZeroNullResult` or `ProteinTreatResult`; assigned primary or secondary family | Input mask, fit call/version, trend/prior/posterior variances, exactness route and coverage. |
| SM10 — DEqMS or proDA selected | Enforce the adapter eligibility table below before execution, export native uncertainty/statistics and distinguish installation from scientific eligibility. | Silent limma fallback under another engine's name; borrowed df/CI; unsupported threshold/null claims. | `EngineEligibility`, native typed differential result; separate model/hypothesis family | Count/dropout evidence, native fields, actual method/version; named errors below. |
| SM11 — Any hypothesis or effect display | Zero-null tests beta=0. TREAT tests a prespecified positive log2 effect margin through limma::treat. Ordinary effect CIs remain effect-estimation CIs, not a TREAT acceptance region. Post-zero-null-BH effect filtering is display-only. Omnibus F tests are distinct endpoints. | Relabeling zero-null q plus abs(log2FC)≥tau as TREAT; nonsignificance as equivalence; significance in one group but not another as an interaction. | `ProteinZeroNullResult`, `ProteinTreatResult`, `ProteinOmnibusResult`; different families | Hypothesis/null, margin, effect scale, CI method/df/level and display-filter flag. |

| SM13 — Influence/uncertainty | Use native backend covariance/df for intervals. Omit whole subjects, including all their technical/repeated observations, for influence diagnostics and refit the fixed model. | Dividing CI endpoints to estimate ratio uncertainty; individual-injection leave-one-out; presenting selected-feature influence as held-out validation. | `EffectInterval`, `InfluenceResult`; intervals inherit endpoint, influence none | CI provenance, omitted-unit IDs, changed n/df, relevant omission counts and ineligible refits. |

Exact unmoderated contrast variance is c' (X_i' V_i^-1 X_i)^-1 c times the feature residual variance, with V_i carrying the actual observation weighting/correlation model. The contrast-as-coefficient fit is the default general path; validate against this independent direct calculation. The shortcut is limited to a proven complete, unweighted, independent one-way group-means design. Positive weights, observed-row subsets and consensus correlation are preserved. For duplicateCorrelation, estimate/report the frozen consensus correlation on the declared fitting universe and reuse it in contrast refits; do not re-estimate a different correlation per contrast. General multi-random-effect/dream models are outside this contract.

### Design × method dispatch (normative)

| Design / input | Primary eligible matrix method | Other allowed method / status | Mandatory rejection |
|---|---|---|---|
| Independent complete finite linear gene matrix, no subject block | CAMERA, competitive; estimate inter-gene correlation (`inter.gene.cor=NA`) | Prespecified ROAST self-contained sensitivity; exploratory fgsea and ORA | `E_PATHWAY_MATRIX_NONFINITE` for required missing/nonfinite matrix; never fill it silently. |
| Paired fixed-subject design | ROAST / mroast with subject encoded in design, no additional random block | Exploratory fgsea/ORA with their actual nulls | CAMERA request fails `E_CAMERA_BLOCKED_DESIGN`; no “fixed-pair CAMERA exception” in this release. |
| Eligible duplicateCorrelation repeated design | ROAST / mroast with verified block/correlation and no duplicate fixed-subject term | Exploratory native-rank fgsea; ORA on eligible measured tests | CAMERA request fails `E_CAMERA_BLOCKED_DESIGN`; unsupported rotation covariance fails `E_ROAST_DESIGN_UNSUPPORTED`. |
| DEqMS/proDA primary | No automatic equivalent CAMERA/ROAST test of that model | A separately named complete-case linear gene-model sensitivity, or native zero-null-rank fgsea / ORA | `E_PATHWAY_ENGINE_MISMATCH` if output claims same-likelihood primary confirmation. |
| Preranked finite unique genes only | None: no sample-level model is available | fgsea, exploratory `preranked_gene_set` null | `E_FGSEA_RANK_INVALID` for incompatible/duplicate/nonfinite ranks; no sample-level inference claim. |

CAMERA records estimated correlations and its official direct-reference output. The `roast` collection adapter calls `limma::mroast(..., midp=FALSE)`; do not pass an unsupported midp argument to a single-set roast reference. It uses set.statistic="mean" and approx.zscore=TRUE; production nrot≥9,999; smaller values are smoke-test-only. For mroast the direction-selected native directional P and the native mixed P are exported separately, with native fields retained and central family adjustment recomputed. Rotation seed/RNG/package/thread settings and attainable resolution are recorded.

fgsea ranks are signed native zero-null statistics (moderated t for limma), with feature mapping fixed first and stable gene-ID ordering for ties. Signed −log10(P) is an explicitly named legacy sensitivity, not a substitute for a native statistic. Export ES/NES/P, native adjusted P, central q, log2err, size, leading-edge membership and warnings. eps=0 is an accuracy setting, not a claim of exact finite enumeration. Gene-set randomization does not provide sample-level confirmation.

### Frozen response vocabulary

| Name | Definition | Status |
|---|---|---|
| `directional_opposition` | sign(t)=−sign(d) for nonzero finite d and t; zero effects are false and nonestimable effects NA | Descriptive. |
| `reversal_index` | −t/d if abs(d)≥dmin and both effects estimable; otherwise NA | Descriptive. |
| `partial_return` | 0.3≤RI<0.8 | Descriptive class. |
| `near_restoration` | 0.8≤RI≤1.2 | Descriptive class only; statistical equivalence is a separate eligible TOST result. |
| `overshoot` | RI>1.2 | Descriptive warning/class. |
| `formal_rescue` | Not a default claim | Only the prespecified eligible conjunction in SM22. |
| `independent_score_test` | Set/signs/transforms frozen off tested samples | Inferential only when SM23–24 pass. |

For a total class function, RI<0 is `same_direction`, 0≤RI<0.3 is `limited_return`, and unavailable RI is `not_evaluable`. These are display residual categories, not added hypotheses. Any RI>1 crosses the estimated control level; `crossed_control=true` records that fact even within the near-restoration tolerance band. RI>2 also gets `residual_exceeds_disease=true`. None of these flags implies rescue. Boundaries are literal; no silent epsilon rounding changes a class.

SM21–SM22 initial qualification is limma with exact same-model covariance/df; DEqMS/proDA equivalence/conjunction requests return E_EQUIVALENCE_INELIGIBLE/E_RESCUE_CONJUNCTION_UNSUPPORTED until separately qualified by an amended contract. For fixed direction s in {−1,+1}, the conjunction components are H0:s×d≤disease_margin, H0:−s×t≤treatment_margin, and the two residual TOST nulls. Use their model-correct one-sided P values and their maximum before conjunction-family adjustment. Effect directions/margins/participant independence are frozen before testing. This adds no default rescue claim. Outputs and diagnostics remain EquivalenceResult/FormalRescueResult as in SM21–SM22 (V085–V086).

TOST with residual r, SE s and df nu uses t_lower=(r+delta)/s, P_lower=1−F_t(t_lower); t_upper=(r−delta)/s, P_upper=F_t(t_upper). The IUT P is their maximum. An eligible joint rescue endpoint does not assume component independence. BH remains subject to its declared dependence assumptions; the conjunction construction does not itself guarantee arbitrary-dependence FDR control.

The two-sided extreme rule is abs(T_perm) ≥ abs(T_observed) − (1e−12 + 1e−10×abs(T_observed)); exact allocation counting includes ties by that rule. Monte Carlo binomial precision describes the underlying full-space tail probability using the B sampled indicators, separately from the corrected reported P.

For independent 4-versus-4 score testing, N=choose(8,4)=70. Audit cases k=2 and k=6 are 2/70 and 6/70, not 3/71 or 7/71. These fractions belong only to synthetic arithmetic/legacy regression fixtures; production derives k and N from the actual eligible allocations. Fully nested selection-aware randomization is not exposed in this version.
